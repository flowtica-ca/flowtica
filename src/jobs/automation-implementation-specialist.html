About Flowtica

Flowtica helps traditional businesses automate messy, manual workflows using automation platforms, APIs, and practical AI. We’re early-stage and hands-on. You’ll work closely with the founder and see the full customer journey from first call to a workflow running in production.

How the role works (important)

The founder builds and maintains the backend platform (infrastructure, reusable modules, and “building blocks”). You own delivery and implementation for new clients by assembling and tailoring those building blocks. When something truly net-new is required, you escalate clearly and we build it together—then you roll it out and document it for reuse.

What you’ll do

  • Run discovery calls and map the “as-is” workflow, constraints, and success metrics
  • Write clean summaries: requirements, scope, acceptance criteria, edge cases, rollout plan
  • Lead delivery execution: timelines, next steps, stakeholder updates, expectation management
  • Configure and launch client workflows using our templates/patterns (low-code first)
  • Connect common systems (email, CRM, PMS/ATS, Slack/Teams, Google/Microsoft 365) using connectors or APIs
  • Test end-to-end, handle exceptions, and iterate after go-live based on real usage
  • Maintain basic runbooks/operational notes so workflows are supportable
  • Identify “reuse/extend” vs “net-new building block,” and escalate with clear problem framing

Must-have

  • 1–3 years in implementations / ops / RevOps / integrations / automation tools or similar
  • Strong communication: can run a call, ask good questions, and write structured notes
  • Comfortable learning technical concepts (APIs, JSON, webhooks) even if you’re not an engineer
  • High ownership and follow-through

Nice-to-have (not required)

  • n8n, Zapier, Make (Integromat), or similar
  • Basic JavaScript/Python for small transforms
  • Basic SQL for checking logs/metrics
  • Any experience in property management, staffing, distribution, or other B2B ops

What we offer

  • ~$50,000 base (depending on experience) + stock options + performance-based raises
  • On-site in Kingston, working directly with the founder
  • Real ownership of end-to-end implementations
  • Fast learning curve in automation, integrations, and practical AI
